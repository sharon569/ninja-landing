יש לכם 1,000 רכישות באתר. בגוגל אדס נרשמות 700. מה קרה לבדיוק 300 רכישות?

**הן באמת קרו. גוגל לא ראה אותן.** והקמפיינים שלכם מקבלים החלטות על דאטה חלקית.

## מה גורם לפער

### 1. iOS 14+ ATT
מאז 2021, אפל מבקשת מהמשתמש אישור לעקוב. **80% מסרבים**. הקליק בקמפיין הולך לאיבוד.

### 2. AdBlock
רוב הגולשים בתחום הטכנולוגיה. **בערך 40% חוסמים** את ה-Google Ads pixel.

### 3. ITP / FLEDGE
דפדפנים חוסמים cookies של צד שלישי. בעוד שנה-שנתיים — **אפס cookies של צד שלישי**.

### 4. הגנות פרטיות
GDPR, CCPA, ולפעמים גם ההגדרות של המשתמש. cookie banner שלא מאשרים = לא נמדד.

## הפתרון: Server-Side Tracking

במקום לשלוח דאטה מהדפדפן ישר לגוגל (שיחסם), אתם שולח אותה **מהשרת שלכם** ישר לגוגל ב-API.

```
[משתמש קונה]
    ↓
[האתר שלכם] ← תמיד עובד, לא חסום
    ↓
[השרת שלכם]
    ↓ (Conversions API)
[גוגל / מטא / טיקטוק]
```

הדאטה לא עוברת דרך הדפדפן של המשתמש → לא נחסמת.

## ה-Stack המומלץ

### Google Tag Manager Server-Side Container
זה הסטנדרט. גוגל מאפשרת לכם להריץ container שלם **בשרת שלכם** במקום בדפדפן.

מה מקבלים:
- כל ההמרות נמדדות (גם מ-iOS, גם מאחורי AdBlock)
- שליטה מלאה על הדאטה
- מהירות אתר טובה יותר (פחות JS בדפדפן)
- אפשרות "להתאים" דאטה לפני שליחה

### Enhanced Conversions
תוסף קל יחסית — שליחת דאטה ראשונית של המשתמש (אימייל מוצפן, טלפון) ביחד עם ההמרה. גוגל קושר את זה לפרסומות, וההמרה נספרת גם אם ה-cookie אבד.

הוסף שורת קוד אחת ב-Tag Manager:
```javascript
gtag('event', 'purchase', {
  enhanced_conversion_data: {
    email: hashedEmail,  // SHA256
    phone_number: hashedPhone
  }
});
```

**Lift אופייני בקוורסיות נמדדות: +15-25%.**

## ההגדרה המלאה ב-3 שלבים

### שלב 1: GTM Server Container
1. צור Server Container ב-Tag Manager
2. הוסף Cloud Run / Vercel / DigitalOcean Droplet (~$5-15 בחודש)
3. הצב subdomain ייעודי: `tracking.yoursite.co.il`
4. הגדירו את ה-Server Container להאזין לסבדומיין הזה

### שלב 2: Web Container → Server
שנה את ה-Web Container הקיים שישלח אירועים ל-Server Container במקום ישירות לגוגל:

```javascript
gtag('config', 'GTM-XXXXXX', {
  server_container_url: 'https://tracking.yoursite.co.il'
});
```

### שלב 3: Server → Google
הוסף ב-Server Container תגי:
- **GA4 Tag** (לאנליטיקס)
- **Google Ads Conversions Tag** (לקמפיינים)
- **Meta CAPI Tag** (לפייסבוק/אינסטה)

לקוח שלנו, חנות איקומרס. תקציב חודשי 60K₪.

- המרות נמדדות: **412** (+47%)

**הקמפיינים** (מה שיותר מעניין):
ROAS שעלה משמעותית, גוגל עכשיו מבין מי מהקליקים הופך לרכישה → מטרגטים יותר טוב, CPA יורד עוד 30% תוך 60 יום.

**ROI על ההשקעה (~6,000₪ הקמה):** השתלמה תוך 14 יום.

## דברים שצריך לדעת

⚠️ **זה לא DIY** — צריך מישהו שמבין GTM ו-Cloud. אם אין לכם, תיעזרו במישהו (אנחנו עושים הקמה ב-15-25K₪).

⚠️ **ההגדרה נכונה היא קריטית** — אם תעשה לבד וטעיות, אתם תהיה במצב יותר גרוע מ-לפני. כי תמדוד **המרות כפולות**.

⚠️ **Privacy Compliance** — תוודא שיש לכם cookie banner תקין. גם בשרת אתם צריכים לכבד הסכמות של משתמשים.
