# Ninja Analyzer — Telegram Bot
## מסמך מוצר v1

**תאריך:** 2026-05-20
**סטטוס:** טיוטה לאישור

---

## הבעיה

היום המפעיל חייב לשבת מול הדפדפן כדי להפעיל סריקות, לבדוק הזדמנויות, לאשר פעולות ולעקוב אחרי תוצאות. כל הלוגיקה קיימת — אבל אין דרך להגיע אליה בלי לפתוח את `seo.samp.ninja`.

## הפתרון

בוט Telegram שמאפשר למפעיל:
1. **לשלוח פקודות** — סריקה, סטטוס, הזדמנויות, אישורים
2. **לקבל התראות** — ממצאים חדשים, ביצוע שהסתיים, בעיות
3. **לאשר/לדחות ישירות** — דרך כפתורים בתוך ההודעה

הכל מהטלפון, בלי דפדפן.

## חוויית המשתמש

### פקודות (מפעיל → בוט)

| פקודה | תוצאה |
|---|---|
| `/clients` | רשימת כל הלקוחות + ציון בריאות |
| `/scan <לקוח>` | מריץ סריקה, מחזיר סיכום ממצאים |
| `/status <לקוח>` | כרטיס סטטוס: ממצאים, הזדמנויות פתוחות, GSC freshness |
| `/opps <לקוח>` | הזדמנויות מדורגות לפי עדיפות, עם כפתורי פעולה |
| `/sync` | סנכרון GSC לכל הלקוחות |
| `/help` | רשימת פקודות |

### התראות (בוט → מפעיל)

| אירוע | הודעה |
|---|---|
| סריקה הסתיימה | סיכום: X דפים, Y ממצאים (Z קריטיים) |
| הזדמנויות חדשות | רשימה מדורגת + כפתור "בדוק עכשיו" |
| דורש אישור | פירוט ההזדמנות + כפתורי ✅ אשר / ❌ דחה |
| Dry run מוכן | Diff (לפני/אחרי) + כפתורי ▶️ בצע / ↩️ בטל |
| ביצוע הסתיים | הצלחה/כישלון + כפתור rollback אם רלוונטי |
| סקירת השפעה | תוצאות 7/14/30 יום: שינוי ב-CTR, מיקום, קליקים |

## מה לא נבנה (מחוץ לסקופ)

- ממשק ניהול חדש — הדשבורד בדפדפן נשאר כמו שהוא
- לוגיקה עסקית חדשה — הבוט משתמש במנועים הקיימים בלבד
- ריבוי משתמשים / הרשאות — בשלב ראשון מפעיל אחד, מזוהה לפי Telegram user ID
- שפות נוספות — עברית בלבד

## ארכיטקטורה בקצרה

```
Telegram Bot API
    ↓ webhook
/api/telegram/webhook (API route חדש)
    ↓
Command Router → מנועים קיימים (סריקה, אודיט, GSC, הזדמנויות, ביצוע)
    ↓
Format → Telegram Bot API → הודעה למפעיל
```

**קוד חדש:** ~4 קבצים, שכבת תרגום בלבד. אפס לוגיקה עסקית חדשה.

**תשתית:** Telegram Bot (חינם, ללא הגבלה, ללא אישורים).

## שלבי בנייה

| שלב | תוצר | מאמץ |
|---|---|---|
| **1 — בסיס** | בוט עם `/clients`, `/status`, `/scan` | יום עבודה |
| **2 — התראות** | הודעות אוטומטיות בסיום סריקה, הזדמנויות חדשות | יום עבודה |
| **3 — אישורים** | כפתורי approve/reject, dry run מ-Telegram | חצי יום |
| **4 — ביצוע** | execute + rollback + סקירת השפעה מ-Telegram | חצי יום |
| **5 — cron** | סנכרון GSC + סריקה אוטומטית (ברקע, עם התראות) | חצי יום |

**סה"כ: ~3.5 ימי עבודה**

## למה Telegram (ולא WhatsApp)

| | WhatsApp | Telegram |
|---|---|---|
| הקמה | Meta Business + אימות + app review | דקה עם @BotFather |
| כפתורים | מקסימום 3 | ללא הגבלה |
| הודעות יוזמות | דורש תבניות מאושרות + חלון 24 שעות | שולחים מה שרוצים, מתי שרוצים |
| עלות | חינם עד 1,000 שיחות | חינם לגמרי |
| מורכבות פיתוח | גבוהה | נמוכה |
